🔧 Manual Clean Install Steps for SociusFit
=====================================================

If the batch files are failing, follow these manual steps:

STEP 1: Open Command Prompt as Administrator
-------------------------------------------
1. Press Windows + R
2. Type: cmd
3. Press Ctrl + Shift + Enter (this runs as admin)
4. Click "Yes" when prompted

STEP 2: Navigate to Project Directory
------------------------------------
cd "C:\Users\foote\Downloads\All Fitness Tracker Files\fitness-tracker"

STEP 3: Verify You're in the Right Place
----------------------------------------
dir package.json
(You should see package.json listed)

STEP 4: Stop Running Processes
------------------------------
taskkill /f /im node.exe
taskkill /f /im npm.exe
(Ignore any "not found" errors)

STEP 5: Remove Old Files (Try Each Command)
-------------------------------------------
del package-lock.json
rmdir /s /q node_modules

If node_modules won't delete:
- Close ALL editors (VS Code, etc.)
- Close ALL terminals
- Wait 30 seconds
- Try: rmdir /s /q node_modules
- If still fails, restart computer and try again

STEP 6: Clear npm Cache
-----------------------
npm cache clean --force

STEP 7: Install Dependencies
----------------------------
npm install

(This will take 2-5 minutes)

STEP 8: Start Development Server
--------------------------------
npm run dev

EXPECTED SUCCESS OUTPUT:
========================
▲ Next.js 15.5.7
- Local:        http://localhost:3000
- Ready in 2.3s

TROUBLESHOOTING:
===============

If "npm install" fails:
- Check internet connection
- Try: npm install --verbose (for detailed output)
- Try: npm install --legacy-peer-deps

If "'next' is not recognized":
- The installation didn't complete properly
- Try deleting node_modules again and reinstalling

If port 3000 is in use:
- Try: npm run dev -- --port 3001

If files are locked:
- Restart your computer
- Run the commands again

ALTERNATIVE: Use Yarn Instead
============================
If npm continues to fail:

1. Install Yarn: npm install -g yarn
2. Remove package-lock.json: del package-lock.json
3. Install with Yarn: yarn install
4. Start server: yarn dev
