## Delivered slice

`/capture/photos` lets an authenticated user select a photo, set its time and
explicitly approve analysis. It uses the existing Socius vision analyzer,
which defaults to Claude through `ANTHROPIC_API_KEY`. No OpenAI key or Decisions
API implementation is required.

Analysis creates an owned review draft instead of a meal. The user can correct
food, portion and macro values, accept the latest revision, or dismiss it.
Acceptance uses the existing atomic capture RPC; only acceptance adds nutrition.
The draft list restores saved estimates after reload. Existing pending-save
controls reconcile interrupted requests before another occurrence is started.

Photo bytes are resized to 1200 pixels and compressed below 1 MB before the
approved request. No image storage is enabled. The transient preview is revoked;
durable drafts and recovery records contain no photo bytes. The existing
capture-v2 pause applies to analysis, corrections and acceptance.

The native Camera-close discovery and local screening work was preserved in its
existing checkout. This web slice does not add unattended photo uploads. See
[ADR-0030](../../decisions/ADR-0030-selected-photo-review-drafts.md).
