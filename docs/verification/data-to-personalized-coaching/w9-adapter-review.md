# Integrated engineering adapter review

Coordinator review on 2026-09-18, after the original reserved set was exposed and before replacement exposure. This review covers verification code, not numerical policy or effectiveness.

Materializers accept facts and rule family; expected decisions, prose assertions and scenario titles do not enter production eligibility. Read adapters call the actual owned context readers, deterministic rules and ranker. The real weekly-review scaffold supplies accepted source-bound observations and calls the production builder. Canonical lifecycle and publication boundary adapters execute the migration chain, authenticated/service-role RPCs and SQL reads. Mocked read transport is explicitly distinct from SQL/RLS proof.

The review identified and corrected these verification gaps before replacement freeze:

* Request-bound client certainty superseded the old surface-only marker fixture. Recovery must prove the exact original request; another request's confirmation cannot release it.
* The source owner must apply to every materialized evidence table, not only meals. The requesting athlete's saved target remains owned separately. Verification status and measurement origin remain explicit inputs.
* Both outcomes in the dual-distance scaffold must retain their independently supplied status. The original helper handled achieved status only for the first outcome; the owner repaired the second-outcome path.
* Transaction adapters reject unsupported combinations instead of silently dropping material facts. Lease, source, response, runtime and day checks read actual RPC results. Initial audit counters and elapsed clock states are documented synthetic prehistory, not production writes available to clients.
* Identical-child capture uses stable child identities, actual frozen commits and current canonical totals. The unresolved retry transport deliberately fails only pending operations; it must not reissue an already committed child. Superseded follow-up uses the production outcome evaluator and persisted event, with actual overlap/attribution limits inspected.

Historical replay and fractional effort execute their real source/validation predicates. A missing recommendation-operation identity or undeclared solicitation gate remains an explicit unvalidated decision label. The review did not invent an advice API or numerical threshold to satisfy those labels.

Original holdout results are consumed development evidence. The separate replacement author receives the public input contract but withholds case bodies and labels from implementation owners until the coordinator freezes the final source/adapter. A passing replacement result, if obtained, establishes only the scoped synthetic engineering contracts; it does not erase the unsuccessful first adapter run or validate the eight underspecified original decision labels.

Final execution counts, replacement exposure and exact source identity belong to [acceptance](acceptance.md). The broader runtime/SQL independent reviews are linked there. No application or migration file changed during this adapter extension, verified against the first candidate manifest.
