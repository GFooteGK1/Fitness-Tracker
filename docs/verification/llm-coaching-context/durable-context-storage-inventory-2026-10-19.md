## Bounded next steps

1. Finish and independently qualify the current local workout-history reader, then seek only its separate release approval. No programming generation added. Preserve explicit empty, unavailable, stale, incomplete and outside-logging-unknown states.
2. Reconcile durable current athlete declarations and inventory actual records through authorized owner reads, reporting timestamps/counts/source coverage per domain. Reconfirmation/save-back needs its own authorization and validated operations; do not silently copy old chat assumptions or numerical targets into canonical state.
3. Design a versioned reference read for the selected LLM. Options are repository-authored reference served by Socius, or a reviewed immutable database/document copy with source version/hash/effective date. A database copy better supports independent retrieval/history but creates a publication/synchronization responsibility. Choose storage/publication deliberately, and make current guidance distinguishable from historical plan policy. No schema or migration is implemented here.
4. Add small factual reads for missing domains, particularly nutrition and body metrics, using existing owner patterns and meaningful temporal/coverage contracts. Avoid a broad host-tool dispatcher or direct unrestricted SQL adapter. Preserve raw-vs-estimated, source/protocol and corrections.
5. Separately plan retirement of embedded programming authoring/agent routes and UI. First establish parity for context access and a future validated plan-save/accept contract for selected-LLM proposals. Then use an explicitly approved rollout to stop new embedded authoring, preserving old plans, provenance, completed-work associations and readable rationale. Keep deterministic calculators as supporting evidence/validation rather than a mandatory hidden programmer. Do not delete historical tables or disable current behavior during this read slice.

The independent foundation assessment favors this incremental evolution over a rewrite. Durable storage is a reusable base; complete populated evidence, comprehensive external reads, a retrievable current playbook and retirement of embedded authoring are unfinished work. Software tests establish behavior, not athletic outcomes.
