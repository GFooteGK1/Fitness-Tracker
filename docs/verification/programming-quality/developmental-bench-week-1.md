## Execution and effort

Loads are total pounds. All listed RPE values are **prescribed targets**, not
performed observations. Record actual load, reps and RPE for each working set,
plus changes, symptoms and overall session response. Do not backfill actual RPE.
Preparation is RPE 3–4. Core is RPE 5–6 with controlled movement. Strength work
uses controlled lowering and a purposeful, fast concentric without grinding.
Movement quality takes priority over completing a stated rep count.

For assistance without a fixed load, select a familiar load or assistance that
allows the listed reps at the target; log the actual selection. Do not invent a
historical weight. If pain appears or control deteriorates, stop the affected
work and reassess. Required recovery is not shortened to meet a time estimate;
record any athlete-chosen time adjustment as a deviation.

### Monday — acceleration, jumps and squat

1. Preparation, 10 minutes: 5-minute easy bike; then A-march 2 × 15 m,
   A-skip 2 × 15 m, 8 bodyweight squats and 2 × 20 m gradual build-ups.
   Rest 30 seconds between drill trips/build-ups; use the remaining preparation
   time for setup/recovery.
2. Countermovement jump, 3 single attempts, **60 seconds between attempts**.
   Use crisp familiar jumps, target perceived effort RPE 6–7; stop if quality
   falls. Rest **2 minutes** before acceleration.
3. **4 × 10 m controlled accelerations**, approximately 80–85% perceived effort,
   **2 minutes between efforts**. This percentage is a coaching cue, not a
   measured speed or RPE conversion. Rest **3 minutes** before squat preparation.
4. Back-squat ramp: **45 × 8, rest 60 seconds; 135 × 5, rest 90 seconds;
   185 × 3, rest 90 seconds; 225 × 1, rest 3 minutes**.
5. Back squat **245 lb, 3 × 3, target RPE 6–7**, **3 minutes between sets**.
6. Rest **2 minutes**. Side plank **2 rounds of 30 seconds per side**,
   target RPE 5–6; **15 seconds to switch sides**, **60 seconds between rounds**.
7. Rest **60 seconds**. Bodyweight calf raise **2 × 12, target RPE 6–7**,
   **60 seconds between sets**. Finish with a **3-minute easy walk**.

## Fixed monitoring identity

New synthetic series: `dev-bench-v1` and `dev-high-handle-pull-v1`. They have no
historical velocity observations. Do not merge them with taper or real-athlete
series just because their loads match.

Each protocol includes the named day's preparation, preceding work, ramp,
**three-minute pre-set rest**, specified **load × 2 reps**, and **three-minute
post-set rest**. Bench uses the same flat bench, bar, marked grip and controlled
touch-and-go technique without bouncing. Pull uses the same trap bar, measured
high-handle setting, stance and dead-stop resets. Fixture comparisons require
the same documented device, placement and mean-concentric-velocity method; those
metadata must be instantiated before any actual sensor comparison.

Use a purposeful fast concentric with controlled technique. Proposed monitoring
effort is submaximal, **RPE no higher than 7**; record actual set RPE and both rep
readings. If it is unexpectedly hard, do not change the load and keep the same
protocol label: record the exception and reassess the subsequent work. Missing
sensor data does not erase a performed repetition. No sensor data, velocity
cutoff or VBT-driven load adjustment is invented for this fixture.

The schedule swap leaves both protocols and their immediate preceding work
unchanged. The changed day of interval training is retained as context when
interpreting Friday's response. Monitoring is separate from working sets and
formal event testing.
