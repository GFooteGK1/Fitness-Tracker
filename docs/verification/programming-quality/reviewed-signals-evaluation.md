## What this evaluation can establish

The system under test is the local adaptation evaluator, targeted-outcome filter and compiler, using synthetic preselected evidence. The decision supported is which engineering gaps must be resolved before the agreed behavior can be evaluated end to end. The failure costs are inappropriate proposals, unsupported claims of progress, lost work records and silently changed prescriptions.

Each check reports `pass`, `fail` or `not_observed`, and a scope of product entrypoint, harness-only diagnostic or fixture fact. A product scope means a real pure function was called; it does not mean hosted behavior was verified. Raw counts must retain those scopes. No average or pass percentage is a coaching score. All six `coachingAssessment` values remain `not_assessed`.

The existing six quality dimensions remain in [the baseline rubric](baseline-and-rubric.md). This focused evaluation covers evidence fidelity, monitoring/adaptation judgment and executable consistency. It cannot establish whole-week suitability, athlete fit, physiological efficacy or prescription appropriateness. The candidate response has not been generated by a model, so semantic review is explicitly unobserved rather than inferred from fixture prose.

The fixture's `proposedReview`, `question` and pending-label fields are never graded as system output. They were written by the case author. Similarly, a record of two performed reps tests fixture preservation only; it cannot establish that logging, storage or the evaluator retained that fact. Mutation tests verify that contaminated protocols, omitted exclusions, fabricated zero readings, lost performed reps and an isolated-spike action change are detected.
