### Execution and effort

- Strength work: propose stopping with about **2–3 reps left**. This target applies
  to the draft strength sets; it is an explicit change from the baseline's 2–4
  RIR for Greg to review. Stop earlier if control or an applicable limitation
  requires it. Eight is a starting target, not a forced minimum. Record fewer
  completed reps truthfully when the reserve target is reached sooner.
- Start near eight reps when capability is unknown. Continue toward 15 only while
  maintaining the intended reserve and control. The upper end is not a requirement
  to finish every set there. This draft does not prescribe a load or difficulty
  increase if 15 remains easy; retain that observation for the next decision.
- Complete both legs for one unilateral round; record each leg's work separately.
  Allow a short side change and additional recovery when needed. Do not infer the
  second side's reps or effort from the first.
- Rest initially **2–3 minutes between strength sets**, extending toward five
  minutes when needed to reproduce the intended intensity. These durations are
  draft parameters, not previously approved universal recovery limits. If more
  recovery is needed, make the time conflict explicit rather than rushing sets.
- Record **RPE for each working set** with the actual reps, movement variation
  and rest. A missing rating stays unknown; no whole-session rating is converted
  into set effort. No numerical RPE-to-RIR mapping is assumed.
- For the bird dog, begin on hands and knees; extend the opposite arm and leg,
  return under control and alternate. Keep the trunk steady and keep breathing.
  End the set if control is lost. Core work has this quality target, not a demand
  to approach failure. Shorten the reach or use one moving limb if needed, and
  record the chosen variation. The single-set dose needs Greg's review.
