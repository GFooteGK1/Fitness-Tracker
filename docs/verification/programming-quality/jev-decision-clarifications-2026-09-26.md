# JEV judgment clarification

Tracking: `Fitness-Tracker-i40.4.6`. Offline development refinement only.

## Confirmed coaching principle

Question to Greg: “Would you include some goal-relevant exposure by default, then
use athlete evidence to decide whether to develop, maintain or temporarily defer it?”
Answer: “Correct”.

Retain each relevant quality in planning. Use evidence and constraints to set its
current role. Default exposure is not an automatic increase, maximal assessment,
fixed dose or requirement for an additional training day. Introduction can be
graded; deferral needs an explicit reason and reassessment condition.

## Separate questions for the next development packet

These exact claims are proposed replacements/contrasts, not new model results or
individually reviewed labels. Greg confirmed the general principle above. Keep
the original eight live requests, approved labels and receipts unchanged.

| Scope | Evidence | Exact claim | Proposed label |
|---|---|---|---|
| Demand relevance | Confirmed goal: improve a standardized timed flying run. | Upright running speed is relevant to this goal. | supported |
| Current emphasis | Same goal; current exposure, comparable performance, tolerance and competing priorities are unknown. | The available athlete evidence justifies increasing upright-speed training now. | insufficient_evidence |
| Default planning | Same goal; no reason for excluding the quality is established. | The demand map should retain upright speed and consider an appropriate exposure while resolving the athlete-specific emphasis. | supported |
| Event attainment, unknown | Only a standing-jump proxy is available; no exact approach-jump assessment. | The available evidence establishes achievement of the approach-jump target in an exact-event assessment. | insufficient_evidence |
| Event attainment, below target | A verified, comparable exact-event assessment is below target. | The athlete met the target in that assessment. | contradicted |
| Event attainment, target met | A verified, comparable exact-event assessment meets the target. | The athlete met the target in that assessment. | supported |

For demand relevance, evaluate the goal-to-quality relationship without demanding
proof that a particular intervention is currently needed. For emphasis, require
athlete context proportionate to the proposed change. Do not use a demand-mapping
verdict as approval of an emphasis or prescription decision.

For event attainment, distinguish absence of an establishing measurement from a
measurement that conflicts with the claim. A below-target result describes that
assessment; it does not establish permanent inability. Proxy improvement alone
does not establish exact-event attainment. These definitions refine the existing
approved unknown-versus-contradicted labels; further calibration remains necessary.
